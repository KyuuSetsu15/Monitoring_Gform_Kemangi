================================================================================
REKAPTES - DASHBOARD MONITORING PESERTA SURABAYA (PROJECT KEMANGI)
================================================================================

Aplikasi web berbasis PHP & MariaDB untuk memantau rekap hasil Pre-Test dan 
Post-Test peserta kegiatan di Kota Surabaya yang terintegrasi secara 
real-time dengan Google Forms / Google Sheets API serta dilengkapi sistem 
backup lokal otomatis (Sync & Fallback).


--------------------------------------------------------------------------------
1. STRUKTUR FILE PROJECT
--------------------------------------------------------------------------------
Pastikan seluruh file berikut berada dalam satu folder utama 
(contoh: C:\xampp\htdocs\php\Kemangi\):

├── db.php          -> Koneksi database MariaDB & fungsi autentikasi user
├── login.php       -> Halaman login admin (dilengkapi fitur lihat password)
├── logout.php      -> Script penghancur session untuk keluar dari sistem
├── testing.php     -> Halaman dashboard utama, penarik data Sheets & backup DB
├── logo.png        -> File gambar logo lokal yang tampil di halaman login
└── README.txt      -> File dokumentasi panduan penggunaan sistem


--------------------------------------------------------------------------------

4. KONFIGURASI GOOGLE SHEETS API
--------------------------------------------------------------------------------
1. Buka file testing.php.
2. Cari variabel $apiUrl di bagian atas file.
3. Pastikan nilainya berisi URL Web App Google Apps Script yang aktif 
   (berakhiran /exec) dan berizin akses "Anyone / Siapa saja".
4. Cara kerja penarikan data:
   - ONLINE  : Data ditarik dari Google Sheets dan langsung menyinkronkan 
               (menimpa) isi tabel peserta_backup di MariaDB.
   - OFFLINE : Jika Google Sheets gagal diakses atau melebihi batas waktu 
               (timeout), sistem otomatis membaca data terakhir dari tabel 
               peserta_backup agar dashboard tidak kosong.


--------------------------------------------------------------------------------
5. CATATAN TROUBLESHOOTING CEPAT
--------------------------------------------------------------------------------
- Data Dashboard tampil 0 : 
  Periksa kembali URL $apiUrl di testing.php, pastikan koneksi internet aktif, 
  atau pastikan tabel peserta_backup sudah dibuat di database kemangi_db.
- Logo tidak muncul di halaman login : 
  Pastikan file logo.png berada di folder yang sama dengan login.php.
- Gagal Login : 
  Pastikan service Apache dan MySQL di XAMPP dalam status Running (hijau).
